I build the systems behind the software: the **Python backends**, the **data pipelines** and the **AI strategy** that turn an idea into something that runs at scale.

I design and ship web backends, shape where machine learning fits, and turn messy data into decisions through rigorous analysis. Alongside the engineering, I write: the technical documentation that makes systems usable, and the creative work that makes ideas land.
